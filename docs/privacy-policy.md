# Wavelit Privacy Policy

_Last updated: 25 October 2026_

Wavelit is a live-wallpaper app for Windows. This policy explains what data it handles.

## What Wavelit collects

**Nothing is sent to us.** Wavelit has no account system, no analytics, no telemetry, no advertising and no crash reporting service. The developer receives no data from your use of the app.

## Data stored on your PC

Wavelit stores these files in `%LOCALAPPDATA%\Wavelit` on your computer:

- your settings and wallpaper library;
- API keys you choose to enter, encrypted with Windows Data Protection (DPAPI) so only your Windows account can read them;
- downloaded videos, shader data and thumbnails (a cache you can clear in Settings);
- log files for troubleshooting, kept for 7 days. Logs never contain API keys.

Uninstalling Wavelit, or deleting that folder, removes all of it.

## Third-party services

Wavelit only connects to the internet when you use these features:

| Service | When | What is sent |
|---|---|---|
| Pexels (`api.pexels.com`, `videos.pexels.com`, `images.pexels.com`) | You search for or download videos | Your search text and your Pexels API key |
| Shadertoy (`www.shadertoy.com`) | You search for or use shaders | Your search text and your Shadertoy API key |
| Web pages you add | You set a web page as wallpaper | Normal web browsing requests to that site |

These services have their own privacy policies: [Pexels](https://www.pexels.com/privacy-policy/) and [Shadertoy](https://www.shadertoy.com/terms).

## Children

Wavelit doesn't knowingly collect any personal information from anyone, including children.
